# Кря и Буль

Браузерная стрелялка с двумя героями:

- **Утка Илона** летит над городом и метает ножички, силы восстанавливает кофе с собой.
- **Карась Миша** плывёт под водой и стреляет пузырями, силы восстанавливают бургеры.

У каждого героя по два уровня и по боссу на уровень: бабка на самокате и бешеная Mitsubishi у утки, злая щука и Сом у карася.

## Как играть

Откройте `index.html` в браузере на ПК или телефоне. Вся игра собрана в этот один файл.

- **ПК:** стрелки или WASD, либо тянуть мышью. Герой стреляет сам. Пробел — суперудар, P — пауза.
- **Телефон:** водите пальцем по экрану. Кнопка со звездой — суперудар. Телефон лучше держать горизонтально.

## Устройство проекта

- `src/shell.html` — разметка и стили.
- `src/js/` — код игры: ядро, звук, графика, фоны, правила, отрисовка, меню.
- `assets/` — готовые спрайты героев.
- `tools/build.py` — собирает всё в один файл: `dist/kryabul.html` и `dist/kryabul-standalone.html`. Копия второго лежит в корне как `index.html`.
